# Changelog

## Unreleased

The Swift port of uxid: prefixed, K-sortable identifiers a person can read,
wire-compatible with the Elixir `uxid` package. No version has been released
yet. The package is in place: the SwiftPM package `uxid` with the library
product and module `Uxid`, Swift 6 with `swift-tools-version: 6.0`, the
platform floors and the build gate. The generation, decoding and validity
checks arrive in later changes.
